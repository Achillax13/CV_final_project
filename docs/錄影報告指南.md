# 第六組期末專案：簡報與錄影指南

這份指南供三位組員用 Windows 製作投影片與錄製期末報告。課程說明要求上傳一份 PDF 報告，並在 PDF 和 Canvas 留言中放入投影片式簡報影片的 OneDrive 連結。課程說明提到影片通常為 15 至 20 分鐘，沒有硬性時長上限。影片目前尚未完成；以下時間安排以約 17 分鐘為目標。

## 講述主線

用一個問題串起影片：PatchCore 已經會融合 layer2 與 layer3，對面積很小的瑕疵，融合是否真的比單用 layer2 好？若把記憶庫容量固定，答案會不會改變？先交代既有方法，再說明本組如何定義小瑕疵、控制比較條件，以及結果的成本與限制。這是實驗設計上的貢獻，無須宣稱發明了新架構。

## 實作段落怎麼講

第 5、6 頁可把程式拆成四個實際步驟，對應原始碼，讓觀眾知道結果如何產生。

1. `study/data.py` 讀取官方 train/test split。原始 mask 先決定小瑕疵分組，圖片與 mask 再接受相同幾何變換。
2. `study/model.py` 使用凍結的預訓練 WideResNet50-2，抽取指定層的 patch 特徵。正常訓練圖的特徵經 coreset 選取後存入記憶庫。
3. 測試圖的 patch 由 FAISS 找最近的正常特徵，再形成異常分數和熱力圖。`study/metrics.py` 計算 AUPRO@0.3 與 AUROC。
4. `run_experiment.py` 保存設定、模型、分數和執行時間；`run_matrix.py` 依序跑完三類、三種特徵、三個種子與兩種尺寸。固定 4096 向量的實驗使用同一套流程。

一段自然的講法是：「我們沒有改 PatchCore 的異常評分核心。先用原始 mask 把小瑕疵分好，避免 224 和 320 像素的裁切改變分組。接著固定 backbone 與評估方式，只切換特徵層和輸入尺寸。最後再固定記憶庫向量數，比較融合在相同儲存量下是否有收益。」投影片可以放流程圖及 `results/figures/` 的一張對照圖，程式碼只擷取足以說明步驟的片段。

## 準備投影片

1. 先以英文期末報告核對數字、圖題與限制。圖可從 `results/audit/`、`results/figures/` 和報告 PDF 取用；不要把整頁 PDF 當成投影片。
2. 每頁標明圖的量測條件，例如 224 或 320 像素、10% coreset 或 16 MiB 固定記憶庫。熱力圖各面板的顯示色階獨立縮放，不能直接把顏色深淺當成數值大小比較。
3. 三人各自練習負責的段落，再合併錄製。第 4、8、11 頁要說清楚限制：解析度比較也改變前處理尺度；小樣本結果屬描述性；實驗沒有在測試 mask 上調參。
4. 若想展示程式，可先錄製簡短片段或用既有 `results/figures/` 圖片說明。81 次正式實驗已完成，影片不需要現場重跑整個矩陣。

## 在 Windows 錄製並輸出

使用 PowerPoint 桌面版時，可在「錄製」功能中逐頁錄音與錄影。先錄一頁並回放，確認麥克風音量、畫面比例及講者交接。PowerPoint 可逐頁重錄；完成後用「檔案 → 匯出 → 建立影片」，選擇已錄製的時間與旁白，輸出 1080p MP4。操作名稱會隨版本略有不同，請以 [Microsoft 的錄製說明](https://support.microsoft.com/en-gb/powerpoint/record-your-presentation)和[影片匯出說明](https://support.microsoft.com/en-us/powerpoint/training/save-a-presentation-as-a-video%E2%80%8B-in-powerpoint)為準。

播放輸出的 MP4，檢查開頭、三位講者交接、圖表字體、音量與結尾。確認影片可從頭播放到尾，再上傳 OneDrive。若學校帳號限制「知道連結的任何人」選項，就使用教師能存取的分享範圍；連結權限設為檢視即可。用未登入的瀏覽器視窗或另一個帳號測試連結，必要時請教師確認存取。OneDrive 的權限選項見 [Microsoft 分享說明](https://support.microsoft.com/en-us/sharepoint/lists/sharepoint-sharing-and-permissions/external-or-guest-sharing-in-onedrive-sharepoint-and-lists)。

## 把影片連結放進 PDF 並交件

取得可開啟的 HTTPS OneDrive 分享網址後，在專案根目錄建立 `docs/presentation_video_url.txt`，檔案只放網址一行。PowerShell 範例中的網址要換成實際分享連結：

```powershell
Set-Content -LiteralPath docs\presentation_video_url.txt -Value 'https://實際的-OneDrive-分享網址' -Encoding utf8
.\.venv\Scripts\python.exe -m pip install -r tools\requirements-report.txt
.\.venv\Scripts\python.exe tools\build_final_report.py
```

重開 `output/pdf/group6_patchcore_final_report.pdf`，確認最後有「Presentation video」與可點擊的 OneDrive 連結。提交時將這份更新後的 PDF 上傳 Canvas，並把同一個影片網址貼在作業留言。若連結變更，更新文字檔、重建 PDF，再重新檢查兩處是否一致。作業截圖的截止時間是 12 月 9 日 11:59pm；以 Canvas 上顯示的課程時區為準。
