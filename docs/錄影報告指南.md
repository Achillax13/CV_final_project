# 第六組期末專案：投影片錄影指南

本組只錄製**投影片式報告**，不需要現場執行程式或示範操作畫面。英文投影片已放在 `output/presentation/group6_patchcore_final_presentation.pptx`；Canva 版也可編輯，請在 Canva 確認組員的分享權限。投影片沒有指定誰講哪一段；錄製前由組員自行決定講述方式。正式 PDF 報告維持全英文。

課程說明要求報告涵蓋 Abstract、Introduction、Related work、Methodology、Dataset、Results and evaluation、Conclusion 及 References，並包含至少兩張圖、一張表、八篇研究文章的引用與完整 bibliography。影片通常約 15–20 分鐘。以下 16 頁簡報把這些重點轉成適合口頭說明的順序，完整書目仍以英文 PDF 為準。

## 只錄投影片的建議流程

1. 在 Canva 或 PowerPoint 打開簡報，逐頁確認圖、表、程式碼及英文文字清楚。若 Canva 匯入後有排版差異，可用本機 PPTX 作為視覺對照。
2. 依照 16 頁約 15–20 分鐘的節奏練習。資料和方法可講得稍慢，讓有電腦視覺背景的觀眾理解比較條件；結果頁逐一說出關鍵數字與限制。
3. 錄影時只分享投影片畫面並收錄旁白。可用 PowerPoint 的「錄製」功能逐頁錄音，再用「檔案 → 匯出 → 建立影片」輸出 1080p MP4。若直接用 Canva 錄製，也要確認最後輸出的是可分享的完整影片。
4. 回放整段影片，檢查麥克風音量、轉場、圖表字體與最後一頁。影片無須重跑 81 次實驗，程式碼和結果已在投影片中。

PowerPoint 的選單名稱可能隨版本變動，可參考 [Microsoft 錄製說明](https://support.microsoft.com/en-gb/powerpoint/record-your-presentation)與[影片匯出說明](https://support.microsoft.com/en-us/powerpoint/training/save-a-presentation-as-a-video%E2%80%8B-in-powerpoint)。

## 分享影片並交件

將完成的 MP4 上傳 OneDrive，設定教師可檢視的權限，並用另一個帳號測試連結。課程說明要求同一個影片連結放在 PDF 報告及 Canvas 作業留言；連結無法開啟會被視為未提交影片。

取得 HTTPS OneDrive 分享網址後，在專案根目錄建立 `docs/presentation_video_url.txt`，只放網址一行，再重建 PDF：

```powershell
Set-Content -LiteralPath docs\presentation_video_url.txt -Value 'https://實際的-OneDrive-分享網址' -Encoding utf8
.\.venv\Scripts\python.exe -m pip install -r tools\requirements-report.txt
.\.venv\Scripts\python.exe tools\build_final_report.py
```

打開新的 `output/pdf/group6_patchcore_final_report.pdf`，確認最後有可點擊的「Presentation video」連結，再上傳 Canvas 並把同一網址貼在留言。作業截圖顯示截止時間是 12 月 9 日 11:59pm；請以 Canvas 顯示的課程時區為準。
