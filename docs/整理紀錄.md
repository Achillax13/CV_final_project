# 專案整理紀錄

整理日期：2026-11-07。

整理時將專案移至目前資料夾，移除原先兩層重複的 `final project/` 目錄。程式與資料的相對路徑維持一致。

## 移除的檔案

- `__MACOSX/`、`.DS_Store`、AppleDouble `._*`：Mac 壓縮檔與檔案管理產生的附加資料。
- `__pycache__/`：Python 可重新產生的編譯快取。
- `.venv/`：從 Mac 複製的 Python 3.12 環境，含 Mac 路徑與平台套件，無法在 Windows 直接使用。
- `data/archives/`：三類資料集的下載壓縮檔。解壓後的圖片、下載來源與雜湊紀錄均已保留。

## 保留的內容

- 根目錄 Python 程式、`study/`、`tests/`、依賴清單。
- `data/mvtec/`：screw、capsule、metal_nut 圖片與標註。
- `.cache/torch/` 與權重紀錄：執行模型所需的預訓練權重。
- `results/`：正式實驗、摘要、資料檢查與驗證結果。早期 baseline 和除錯紀錄也保留作為實驗證據。
- `vendor/patchcore-inspection/`：第三方原始碼、版本資訊、授權與原始附帶檔案。
- 提案 PDF、README、中文指南與專案進度文件。
